# DSH · 鲸与鱼 —— 手机端界面层

一个可以直接在手机浏览器（或双击本地文件）打开的 AI 陪伴 App 界面原型。
**纯界面 + 假数据，不发任何网络请求，没有构建工具，没有任何依赖。**

> 软件名：**DSH · 鲸与鱼**（`app.js` 里的 `ME`＝「小鱼」是 AI 角色，
> `USER_DEFAULT`＝「游道の世.」是我自己，两码事。）

一级四个页面 **首页 / 聊天 / 朋友圈 / 我的**；**设置**、**编辑资料**、**聊天详情** 都是二级页。

---

## 怎么打开

**方式一**：双击 `index.html`（`file://` 下可正常运行）。

**方式二**：
```bash
python -m http.server 8080     # 或 npx serve .
```
手机浏览器访问 `http://<电脑局域网IP>:8080`；桌面浏览器 F12 切 375×812 设备模拟。

## 页面结构

```
首页        横幅（右上：搜索 / 通知 / 齿轮）→ 角色卡 → 四圆按钮带
            → 今日心情｜最近动态 双栏 → 能力四钮 → tab
聊天        横幅（搜索 / 新建）→ 全部/好友/群聊 分段 → 会话面板 → 提示
聊天详情    ‹ 横幅 + 会话名 → 白色上浮面板 → 消息 / 空状态 → 输入栏     （二级页）
朋友圈      横幅 → 角色卡 → 全部/好友 + ＋ → 动态流 / 空状态
我的        横幅 → 我的头像 + 名字 + 签名 → 编辑资料/设置/检查更新 → 服务连接 → 版本
设置        ‹ + 药丸标题「设置」→ 后台推送卡 → 消耗显示卡 → 五行分组     （二级页）
编辑资料    ‹ + 药丸标题「编辑资料」→ 大头像（可换）+ 名字 + 签名 + 保存 （二级页）
```

## 交互

### 首页
- 右上三个玻璃圆钮：搜索 / 通知（无动作）、**齿轮 → 设置**
- 四圆按钮：**和我聊天**（进聊天详情）/ 语音通话 / 发动态（切朋友圈）/ 一起创作
  - 语音通话、一起创作点了弹「xx · 敬请期待」
- 「今日心情」：**已清空**，显示「今天还没写心情。」（`MOODS = []`，等插件推数据）
- 「最近动态」：**整块卡片可点**（不只是右上角 ›），点了进朋友圈；支持键盘 Enter / 空格
- 所有可点元素都有按下反馈（图标缩到 0.92~0.96、按钮/卡片底色加深）；**「我的」页的行除外**（按要求去掉）
  - 设置页的行按下时是**从卡片左沿到右沿的一整条高亮**：`.group` 有 14px 内边距，直接给 `.row` 铺底色会内缩一圈、
    露出白边，所以改用 `.row:active::before` 向左右各撑 14px，并给 `.group` 加 `overflow: hidden` 让卡片圆角把高亮裁掉
  - 会话行本身就是整张卡片，直接铺底色即可（`.session-panel` 已 `overflow: hidden`）
- 能力四项：绘画创作 / 听歌音乐 / 学习成长 / 一起娱乐
  - **四个钮外观完全一致，没有开/关态**；只有按下时图标变灰缩小，松手复原（留给后续接换界面）
  - **点击弹提示 `xx · 敬请期待`**（1.4s 后自动消失）；提示条 `#chatToast` 已提到 `.phone` 层，任何页面都能用
- **角色卡「在线」后面也跟同一个峰谷倒计时**：`在线 ｜ 谷期 12:58:24`（浅色底上用深红/深绿，不带深色描边）
- 「最近动态」：没有动态时显示「她还没有新的动态。」

### 聊天
- 三个分段**真的会过滤**：全部（1 条：小鱼）/ 好友（1 条）/ 群聊（0 条，显示空状态）
- **右上放大镜 = 会话搜索**：点开出现搜索条（自动聚焦），按会话名 / 最后一条消息过滤，实时出结果，
  搜不到显示「没有找到「xx」」；「取消」或 Esc 收起并清空，离开聊天页也会自动收起
- 右上 ＋ （建群）点一下弹「建群 · 敬请期待」（原来那行「点右上角 ＋ 可以建群…」已删掉）
- **长按会话行 480ms 出悬浮菜单**（仿微信：贴着这一行弹出的小白卡片 + 指下小三角，不再是半屏抽屉）：
  `置顶聊天` / `设置特别关注` / `标为未读`
  - 置顶：会话名前出现「置顶」小标，再点一次变「取消置顶」
  - 特别关注：切换并提示；**头像右下角出现「粉底红心」小角标**（16px 粉圆 + 白描边 + 红色爱心，
    聊天详情头部头像用 18px 同款），再点一次取消
  - 标为未读：行尾出现红点，进会话后自动消失
  - 短按仍然进聊天详情；长按只挡「松手那一下」的误触（700ms 后恢复正常）；点空白处关闭
- **长按气泡 420ms 出悬浮菜单**：`引用` / `多选` / `删除`（删除是红色）
  - 引用：输入框上方出现引用条（谁 + 内容 + ×），发送后气泡里带一个浅色引用块；
    我方蓝色气泡里的引用块是浅色半透明 + 白字，保证可读
  - 删除：直接删这一条，提示「已删除」
  - 多选：进入多选模式，每条左侧出现圆形勾选圈，选中的圈变蓝打勾；底部输入栏换成
    「取消 / 已选 N 条 / 删除」，删完退出多选
  - 多选模式下长按菜单不再弹（避免和选中冲突）
- 会话行显示名字、最后一条消息、时间；没有消息时显示「还没有消息，说点什么吧。」
- 点任一会话进聊天详情：标题 / 头像跟随会话；没有消息时面板正中显示空状态
- **头部状态行带 DeepSeek 峰谷倒计时**：`在线 ｜ 峰期 00:11:00`
  - 规则（北京时间，按本机本地时间算）：
    - **高峰（贵 ×2）**：周一至周五 `09:00–12:00`、`14:00–18:00`
    - **谷价（正常价）**：其余全部 —— `12:00–14:00`、`18:00–次日 09:00`、**周六日**、**法定节假日**
    - 节假日：往 `HOLIDAYS` 数组里加 `'YYYY-MM-DD'` 即按谷价算（含调休放假的）
  - **只显示当前那一个**：峰期只有峰期倒计时（红），谷期只有谷期倒计时（绿），没有箭头和第二段时间
  - 倒计时＝距下一次峰↔谷切换还有多久，每秒刷新，`HH:MM:SS`，等宽数字防抖动；无底色块，只配描边阴影
  - 切换只发生在整点边界（00:00 / 09:00 / 12:00 / 14:00 / 18:00），所以用「扫边界」求下一次切换，不用逐分钟穷举
  - 「正在输入…」只替换前面那截文字，倒计时不受影响
  - 首页角色卡的倒计时和这里是**同一个节点组**（`SLOT_NODES = ['slotNow','slotHome']`），一次 `renderSlot()` 同步刷新，不会出现两边秒数不一致

## 软键盘（这一版重点修的）

之前打完字收起键盘，底部会露出一截深蓝 + 浅蓝的色带、看着像卡住。原因和修法：

- `visualViewport` 的高度是**逐帧**变回来的，原来每次 resize 都把 `.phone` 的行内
  `height` 改一次，于是中间几帧外壳比视口矮，底下就露出 body 和渐变的边
- 现在分两种情况：**键盘在**（`innerHeight - visualViewport.height > 80`）才写行内高度；
  **键盘收起**立刻把行内 `height` 清空、交还给 CSS 的 `100dvh`，不再逐帧回弹
- 所有 resize 用 `requestAnimationFrame` 合并，避免一帧内多次改布局

### 手机返回键（安卓物理返回 / 手势返回）

用 `history` 压栈实现，规则：

- **首页永远只有一层**：在首页按返回，交给系统退出 App（网页里就是离开页面）
- **其它一级页压在首页之上**：聊天 / 朋友圈 / 我的 里按返回 → 回首页
- **一级页之间互切不叠层**（用 `replaceState`）：我的 → 朋友圈 再按返回，是回首页而不是回我的
- **二级页再叠一层**（`pushState`）：聊天列表 → 聊天详情，返回回聊天列表；我的 → 设置，返回回我的
- 页面里的 `‹` 返回按钮统一走 `history.back()`（`.js-back`），所以它和物理返回键行为一致

实现位置：`go()` 里按「目标页 / 来源页是不是一级 tab」决定 `pushState` 还是 `replaceState`，
`window.addEventListener('popstate')` 里回放；启动时先 `replaceState({page:'home'})` 垫底。

> 打成 APK 后要在原生侧把系统返回键转给 WebView（Capacitor：监听 `backButton` 后调用 `webView.canGoBack() ? goBack() : finish()`），
> 否则原生会直接退出 App。这一步在 `打包成App.md` 里补了说明。

### 软键盘弹出时不挤掉上面的横幅

- 外壳 `#phone` 的高度**由 JS 按 `visualViewport.height` 写死**（`syncViewportHeight()`），
  不再直接吃 `100dvh` —— 键盘弹起时只改这一个高度
- 横幅 `flex: none` + 固定高度（聊天页 208 / 首页 268），所以**横幅高度一点不变**，
  被压缩的只有消息列表（`.sheet` 是 `flex: 1`）
- `body { position: fixed; inset: 0 }`，防 iOS 聚焦输入框时把整页往上顶
- 键盘弹起（高度骤降 > 60px）时自动滚到最新消息
- 实测（375 宽，视口 812 → 模拟 500）：横幅始终 208、消息区 604 → 292、输入栏 443–500 贴着视口底、无文档溢出；
  视口恢复后完全还原

### 离线（断网也能进）

- `sw.js` 预缓存整套外壳（html/css/js/manifest/图片，缓存名 `dsh-whale-v1`），策略「缓存优先 + 后台更新」
- **只在 https / localhost 注册**，局域网 `http://IP:8080` 下 Service Worker 不生效（安全上下文限制）
- 断网时的消息行为（`navigator.onLine`）：
  - 发出去的消息照样进列表，气泡**左侧**出现红色感叹号，点一下重发
  - 仍离线 → 提示「还是没有网络，等一下再试」；已联网 → 转圈 → 600ms 后正常并触发对方回复
  - 状态行变「离线」；恢复网络时提示「网络恢复了，点红色感叹号重发」
  - 语音消息同样走 `pushMine()`，共用这套状态
- **峰谷倒计时完全不依赖网络**：纯本地时间算出来的，断网照常每秒走（实测断网 3 秒内 `12:09:41 → 12:09:39`）
- 时段判定按**固定 UTC+8（北京时间）**，不用设备时区 —— 用 `new Date(ms + 8h)` 后只取 `getUTC*`，
  所以手机/电脑时区设错也算得对；唯一影响是**系统时间本身被改错**，那样倒计时会跟着错（要防这个就得让后端下发时间）
- **打成 APK / 装成 PWA 的完整步骤见 `打包成App.md`**
